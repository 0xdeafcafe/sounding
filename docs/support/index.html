Send it from TestFlight

If you’re on the beta, this is the quickest way. Feedback from TestFlight reaches me with your device, system version and build already attached, which saves us both an email or two.

  1. Open TestFlight and pick Sounding.
  2. Tap Send Beta Feedback.
  3. Say what you were doing, what you expected and what actually happened.
  4. Add a screenshot if it helps, then send.

Take a screenshot while Sounding’s open and TestFlight offers to send it as feedback there and then. If the app crashes, it asks whether you want to send the crash report (please do).

What helps

  • Which device: iPhone, iPad, Apple Watch, Apple TV or Mac.
  • What you did right before it went wrong.
  • Whether it happens every time.
  • The track or mix, if it’s only that one.
