# Now Playing: decisions (2026-11-06)

1. Now Playing is always dark, on every platform, regardless of the system appearance.
2. iPhone: while a mix (long DJ set with a tracklist) plays, Tracklist takes the Comments slot in the bottom row and Comments moves into •••. For normal tracks the bottom row is Comments · Output · Up Next.
3. Long titles fade out at the trailing edge; no marquee.
4. Mac: the transport moves into the window toolbar, like Music on macOS 26. No bottom transport bar.
5. The pane is called "Tracklist"; saved tracklists live under Library → Setlists.
